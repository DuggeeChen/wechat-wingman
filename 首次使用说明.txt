桌面搭子 v2.6.0 — Windows 便携版

完整解压 ZIP，双击 WeChatStrategist.exe。
首次向导填写 OpenAI 兼容 Chat Completions 地址、支持图片的模型及 API Key。
打开具体微信聊天，点击「一键读取并生成」，选择、编辑、复制后，自己粘贴发送。

「更多 → 模型与 API 设置」可以换供应商、获取模型列表、测试连接。
「前情 / 纠正」补充上下文，点击身份按钮纠正说话人。
目标和底线属于可选「特殊要求」，不用先填写。
「更多 → 清理截图与临时数据」清理遗留截图、日志和识别指纹，不清空聊天或配置。

密钥在当前用户 Windows 凭据管理器，个人数据在 %LOCALAPPDATA%\微信军师。
当前聊天和前情只在内存，关闭后清空。识别、生成会发送相关内容给配置的模型。
旧画像保留手动入口；主流程不自动建画像或调用 Jev。发送前请核对身份与建议。

重新配置.bat 可重开首次向导。版本记录见 CHANGELOG.md，详细说明见 README.zh-CN.md 与 docs\PRIVACY.md。
