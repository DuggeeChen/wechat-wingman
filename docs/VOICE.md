# 语气与回复方向

方向表示这句话想做什么，语气表示如何说。首轮已生成的不同方向可以直接切换查看；切回来复用最新回复。需要新内容时，在对应卡片上点「换一条」。

当前选中的风格名称和说明会作为明确的写作要求传给模型，并与聊天原话分开。它约束用词、句式、节奏、称呼分寸、语气词和表情，不添加新的关系、事实或承诺。修改当前风格后需要重新生成。

| 内置风格 | 主要表达要求 |
|---|---|
| 默认 | 顺口短句，直接接话，少用书面连接词和礼貌前缀。 |
| 商务 | 清晰、专业，说明要点或下一步，少语气词，不用表情和亲昵称呼。 |
| 亲密 | 熟人语感，适量玩笑和语气词，最多一个表情，熟络程度跟随对话。 |
| 上级 | 尊重、简练，接住要求，说明已知进度或需要确认的事，不反复保证。 |
| 客套 | 温和礼貌，可自然感谢或商量，意思明确，避免堆敬辞。 |

原版内置的短描述在读取时升级到内存。自定义名称、修改过的说明和空说明保持原样，个人配置不自动写回。可在「更多 → 语气风格库」查看和修改实际使用的说明。

一次同情景实测使用以下完全虚构的对话：

> 对方：昨天你帮我把那个问题说清楚了，真的谢谢你。
> 我：能帮上就好。
> 对方：你这人还挺靠谱的，以后有事我还找你哈。

共同方向是回应认可，未来是否帮忙仍按实际情况决定。三个请求使用同一模型、同一上下文和同一方向，只改变风格要求：

| 风格 | 本次实际输出 |
|---|---|
| 默认 | 哈哈过奖了，真有事到时候再说，能帮上我肯定搭把手。 |
| 商务 | 谢谢你的认可。上次那个问题能说清楚就好。之后有需要可以先跟我讲，我再按实际情况定能不能帮上。 |
| 亲密 | 哈哈，被你这么一夸我还有点飘。以后有事你就说，具体能不能帮上咱们到时候再看，别跟我客气🙂 |

这组样例体现了用词、节奏和熟络程度的差异。模型输出有随机性，一组样例不能保证所有真实聊天的效果。不同方向应改变沟通行动或立场；同一方向换写保持其用意。程序会拦截原样及高度相近的文本，但文字相似度不等于完整的语义判断。
